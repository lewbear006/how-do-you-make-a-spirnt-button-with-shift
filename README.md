# Rent Quest (Pygame)

A small top-down shooter where the goal is to pay rent by hunting monsters, taking jobs, and upgrading your gear. Built with Pygame.

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Controls

- WASD: Move
- Mouse: Aim
- Left Click: Shoot
- E: Interact (NPC/Shop/Rent)
- Esc: Pause

## Notes

- Game saves to `save.json` on exit.
- Windowed by default 1280x720.
